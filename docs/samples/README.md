# Sample footage (#34)

Overhead camera view of the lab breadboard, for building the overlay engine (#11) and the overlay spec (#26) without the real setup.

**Setup:** iPhone 17 Pro Max as a Mac webcam (Continuity Camera, back camera pointing straight down, landscape), on a box stand. Camera height ≈ **25 cm** above the table. Venue lighting, no extra lamp.

| file | what |
|---|---|
| `board-empty-01..03.jpg` | Empty 830-point board (1600×900, cropped from the camera feed) |
| `hand-wire-01.jpg`, `hand-wires-02.jpg`, `hand-wire-03.jpg` | Hand holding jumper wires over the board |
| `overhead-15s.mp4` | 15 s clip of the same view, with a hand bringing in wires (1280×720, no audio) |
| `setup-stand-01.jpg` | The stand itself, for reference |

Measurements: the board is ≈ **1030 px wide in the 1600 px frames** (≈ 65% of the frame width, ≈ 1900 px at the camera's native 2940 px).

Known issues with this first batch, to fix in the next one:
- The board sits near the top of the frame, and the stand's legs show in the bottom corners. It isn't taped down yet, so it shifts a little between frames.
- No parts on the board yet. Photos with the Lab 1 and Lab 2 parts placed (`labs/README.md`) come next.
