Wire the probe pod on the mini board

#5 Wire the probe pod35 mincritical path
Why: the pod is Bench's voltmeter. Four probe wires go into the student's board, and the Uno reads their voltages 20 times a second. The button is “talk to Bench” and the RGB LED shows Bench's state (listening, thinking, speaking). It also powers the lab board, so everything shares one ground.

How to hold the board

Long edge horizontal, trench across the middle. Number the 17 columns 1 → 17 from left to right. Above the trench the holes are a b c d e (top to bottom), below it f g h i j. The 5 holes of one column on one side are connected (one “node”); columns are separate, and the two sides of the trench are separate.

① Power nodes: column 16 top = 5 V, column 17 top = GND (the mini board has no rails, so these two columns stand in for them)
② Probes: Uno pin → top hole · 10 kΩ across the trench (safety resistor, limits current to <0.5 mA) · long probe wire from the bottom hole
③ RGB LED: long leg = shared pin; the black wire from 11a loops round to 17d (GND). R/G/B each go through a 220 Ω to D9/D10/D11
④ Talk button: across the trench. Only the diagonal legs (15f, 17e) are used, so it works whichever way round it sits
⑤ Lab power: 16b → lab + rail (red line), 17c → lab − rail (blue line)

Do it in this order

Test the wiring (about 5 min)

Plug the Uno into the laptop, then:

uv run firmware/sanity/check_pod.py --upload

It uploads a tiny test sketch, then asks you to:

  1. plug all 4 probe wires into the lab board's − rail → each should read ≈ 0
  2. plug them all into the + rail → each should read ≈ 1023
  3. hold and release the button → 0 while held, 1 when released
  4. watch the LED: red → green → blue → off. If it never lights, your LED is common-anode: move the 11a jumper from 17d to 16c (5 V) and run the test again. The script's hint says “27a”, which is the big-board name for this same jumper.
Done when: the summary says all checks pass and names the LED type. Then take a straight-down photo of the pod (it goes in the README) and save it as docs/visuals/pod-wiring-photo.jpg.

The 3.3 V step

Run a jumper from the Uno's 3.3V pin to a free row on the lab board (say 50a), then put all 4 probes in that row (50b–e). This reading is also what I use to tune the pod's accuracy in step 5.

The divider step (optional, skip with s)

Two 10 kΩ in series from the + rail to the − rail. Put the yellow probe where they meet. It should read half of vcc.

Plug the probes in once: Y → row 6 · B → row 10 · G → row 13 · W → − rail. Then the script steps through these states. Set each one up, press Enter, keep your hands off for 2 s, then undo it:
